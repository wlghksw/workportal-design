2워크플로우 및 기능 역설계

📦 클래스101만의 킬러 기능 — 물리적 키트 시스템

🎁 수강 신청 시 관련 재료(키트)를 집으로 배송하는 O2O 방식

강의를 구매하면 수업에 필요한 모든 재료(붓, 물감, 원단, 도구 등)를 박스에 담아 배송합니다. "어디서 재료를 사야 하지?"라는 실천의 장벽을 원천 제거합니다. 공예·드로잉·요리 카테고리에서 특히 강력하며, 이는 Class101이 타 플랫폼과 가장 명확하게 차별화되는 기능입니다.

4크레용스쿨을 위한 벤치마킹 인사이트

1

교구재 대여 → 키트 배송 연계 모델

크레용스쿨은 이미 로봇·코딩 교구를 보유하고 있음. Class101처럼 강의 등록 시 교구재 대여/배송 상태를 수강생 페이지에서 직접 추적할 수 있도록 연동하면 큰 차별화 포인트가 됨.

2

시청 시간 기반 자동 정산 도입

현재 엑셀 수동 정산 → Class101처럼 강의 횟수/수강 데이터를 시스템이 집계하여 자동으로 정산서를 생성하는 파이프라인 구축. 운영팀 공수 90% 절감 가능.

3

1:1 피드백 코칭 기능

진로 분석 리포트를 바탕으로 강사가 수강생에게 개인별 1:1 피드백을 제공하는 기능 도입. "코칭 세션" 단위로 별도 판매하면 추가 수익원 확보 가능.

4

국비 바우처 연계로 결제 장벽 해소

크레용스쿨의 로봇·AI 코딩 강의를 정부 평생교육이용권 또는 직업훈련바우처와 연계하여 수강생이 무료 또는 저렴하게 수강할 수 있도록 설계.
